# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée de PrepaTrack reçoit les correctifs de sécurité.

## Signaler une vulnérabilité

N'ouvre pas d'issue publique pour une vulnérabilité ou une fuite potentielle. Utilise
le bouton **Security → Report a vulnerability** du dépôt afin d'envoyer un rapport
privé au mainteneur.

Indique, sans joindre de donnée réelle de préparateur :

- la version ou le numéro de build concerné ;
- les étapes minimales pour reproduire le problème ;
- son impact possible ;
- une proposition de correction, si tu en as une.

Ne fournis jamais de mot de passe, code personnel, numéro de badge réel, jeton Vercel,
clé Supabase de service ou chaîne de connexion à la base. Si un secret a été exposé,
révoque-le immédiatement avant d'envoyer le rapport.
